One line that roasts an alarm clock for ringing at 6 AM on a Saturday morning.

`main.py` (standard library only) writes the roast to `entry.txt` in the
output directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`):

```sh
python3 -S main.py
```
